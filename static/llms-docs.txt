## Commands Reference

- [Commands index](__DOCS_BASE_URL__/commands/): Full catalog of Redis commands grouped by category with syntax, parameters, and behavioral notes.
- [AUTH](__DOCS_BASE_URL__/commands/auth/index.html.md): Client authentication against Redis using passwords, ACL users, and connection security.
- [DEL](__DOCS_BASE_URL__/commands/del/index.html.md): Deletes one or more keys immediately and reclaims memory for those keys.
- [EXPIRE](__DOCS_BASE_URL__/commands/expire/index.html.md): Sets a TTL in seconds on a key for time-bound cache and session semantics.
- [GET](__DOCS_BASE_URL__/commands/get/index.html.md): Reads a string value for a key; returns null when the key is absent.
- [HSET](__DOCS_BASE_URL__/commands/hset/index.html.md): Writes field–value pairs on a Redis hash, creating the hash when needed.
- [SET](__DOCS_BASE_URL__/commands/set/index.html.md): Stores a string value with optional NX/XX, expiration, and conditional semantics.
- [TTL](__DOCS_BASE_URL__/commands/ttl/index.html.md): Returns remaining seconds until key expiry for keys with a timeout.

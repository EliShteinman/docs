*By Sowmya Narayanan, Shyam Kathiresan · Published 11 July 2024 · updated 11 June 2025*

![Blog tile image](/images/site-mirror/a00b6a3a1a15c121fb02f70437bf6b71cc0488e3-772x552.webp)

Starting today, Redis Cloud Essentials is available on Google Cloud Marketplace. It’s never been easier to deploy and manage Redis in the cloud while billing through the Google Cloud Marketplace.

**What is Redis Cloud Essentials?**

Redis Cloud Essentials is a managed Redis service that makes getting started with Redis on Google Cloud simple and affordable. Whether you’re new to Redis or need a lightweight Redis solution, it’s perfect for developers of all levels working on small apps or development environments.

![Redis Cloud Essentials](/images/site-mirror/b30a5d8756b8b7bd6101acf51cd7cd0b2f0d9e36-451x512.webp)

**Why choose Redis Cloud Essentials?**

- **Simple and easy to use:** Redis Cloud Essentials is easy to set up and use. Get a Redis instance up and running in minutes.
- **Budget-friendly:** Start for free with our 30 MB plan, ideal for learning and development. For small-scale production, affordable paid plans start at just $5 per month.
- **Highly available:** Enjoy high availability (HA) features uptime up to 99.99%. With Redis Cloud Essentials, your Redis instance is always available, even during a failure.
- **Backups and disaster recovery:** Never lose your data with automated backups and disaster recovery features.**Enterprise features:** Enjoy enterprise features like Data in Transit encryption, Role Based Authentication, and access to Redis tools like vector database, Search and Query, JSON, and Time Series.
- **Integration with Google Cloud:** Redis Cloud Essentials works smoothly with Google Cloud. Manage your Redis instances alongside your other Google Cloud resources, or access it through Google Cloud Marketplace.
- **Easy upgrades:** Need higher throughput, or more features like data persistence, durability, VPC Peering, or Multi-site Active-Active global distribution? No problem—migration between Essentials plans is simple and only takes a few minutes. Just follow these steps.

**Pricing and availability**

Redis Cloud Essentials is available on Google Cloud Marketplace in select regions around the world. Start for free with the 30 MB plan. Paid plans begin at just $5 per month for 250 MB of storage with no replication, and $7 per month for 250 MB of storage with single zone replication.

**How to get started**

Redis Cloud Essentials gets you up and running fast. Visit the Redis Cloud listing on the Google Cloud Marketplace and hit the Subscribe button to launch a new Redis instance.

Redis Cloud Essentials is a powerful and affordable managed Redis service that makes it easy to deploy and manage Redis on Google Cloud. With its simple setup, cost-effective pricing, and high availability features, Redis Cloud Essentials is the perfect solution for developers of all levels.

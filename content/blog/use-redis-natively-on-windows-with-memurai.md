*By Blair Pierson, Sr. Director- AI/Tech partners AMER · Published 28 July 2025 · updated 31 July 2025*

![Use Redis natively on Windows with Memurai](/images/site-mirror/144f550e34ba01782431848acad00371e1b71789-772x552.webp)

Redis is now available to use natively on Windows. We’ve partnered with [Memurai](https://www.memurai.com?utm_source=redis&utm_medium=referral&utm_campaign=redis_blog_Q2_2025) to develop Memurai Enterprise Edition, a fully compatible and officially supported [Windows port of Redis](https://www.memurai.com?utm_source=redis&utm_medium=referral&utm_campaign=redis_blog_Q2_2025) that brings the full power and performance of Redis to Windows, natively and seamlessly.

Memurai gives you the speed, simplicity, and reliability of Redis, fully optimized for your Windows environment. It’s ideal for production use with unlimited uptime, host connections, and RAM utilization.

Visit the [tutorial in our developer hub](https://redis.io/learn/howtos/how-to-run-redis-on-windows-natively-with-memurai) for full details on how to install and use Memurai Enterprise Edition, and visit [memurai.com](http://memurai.com) for installation packages and more information.

Memurai Enterprise Edition is free to try for 90 days. [Register here](https://portal.memurai.com/auth/register?utm_source=redis&utm_medium=referral&utm_campaign=redis_blog_Q2_2025) to start building today.

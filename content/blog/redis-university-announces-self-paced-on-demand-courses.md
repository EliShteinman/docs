*By Simon Prickett, Curriculum Software Engineer · Published 3 April 2020 · updated 27 March 2025*

![Blog tile image](/images/blog/47b48b93f4d549f318229af5b7364f4b7cd9bda8-386x260.webp)

[Redis University](https://university.redis.com/) is pleased to announce the immediate availability of free, self-paced, on-demand online courses. A lot has changed in recent weeks, and many of us are now at home, perhaps a bit more than we’d like to be.

To help make this shelter-in-place time as productive as possible, we figured this would be a great time to give the Redis community the chance to complete as many courses as you can, all at your own pace. Take as many courses as you like—just be sure to complete them before they close on May 12, 2020.

Right now, for a limited time, five of our courses are immediately available for self-paced learning:

[Watch the video](https://www.youtube.com/watch?v=2E1MVl29P0U&feature=emb_title)

### [RU101: Introduction to Redis Data Structures](https://university.redis.com/courses/ru101/)

For those new to Redis, this course offers a thorough introduction to Redis and its data structures.

*Check out the intro video *[*here*](https://www.youtube.com/watch?v=2E1MVl29P0U&feature=emb_title)*, and learn more about the course *[*here*](https://university.redis.com/courses/ru101/)*.*

[Watch the video](https://www.youtube.com/watch?v=c1NJgoXNYrE&feature=emb_title)

### [RU202: Redis Streams](https://university.redis.com/courses/ru202/)

A logical continuation to RU101, the Redis Streams course covers the most sophisticated Redis data structure: Streams.

*Check out the intro video *[*here*](https://www.youtube.com/watch?v=c1NJgoXNYrE&feature=emb_title)*, and learn more about the course *[*here*](https://university.redis.com/courses/ru202/)*.*

[Watch the video](https://www.youtube.com/watch?v=V8THJ-BaQw4&feature=emb_title)

### [RU201: RediSearch](https://university.redis.com/courses/ru201/)

In RU201, you’ll learn all about full-text indexing in Redis using the RediSearch module.

*Check out the intro video *[*here*](https://www.youtube.com/watch?v=V8THJ-BaQw4&feature=emb_title)*, and learn more about the course *[*here*](https://university.redis.com/courses/ru201/)*.*

[Watch the video](https://www.youtube.com/watch?v=CmQMdJefTjc&feature=emb_title)

### [RU102J: Redis for Java Developers](https://university.redis.com/courses/ru102j/)

Write a full-fledged application with Java and Redis! This language course describes many of the patterns you’ll use to write efficient Java code against Redis.

*Check out the intro video *[*here*](https://www.youtube.com/watch?v=CmQMdJefTjc&feature=emb_title)*, and learn more about the course *[*here*](https://university.redis.com/courses/ru102j/)*.*

[Watch the video](https://www.youtube.com/watch?v=Ik1WXPX3WNU&feature=emb_title)

### [RU102JS: Redis for JavaScript Developers](https://university.redis.com/courses/ru102js/)

This course takes a similar approach to RU102J, but is for developers wishing to learn more about best practices for using Redis in Node.js applications.

*Check out the intro video *[*here*](https://www.youtube.com/watch?v=Ik1WXPX3WNU&feature=emb_title)*, and learn more about the course *[*here*](https://university.redis.com/courses/ru102js/)*.*

Redis University turns two years old in April, and there are few better ways to learn Redis than with a Redis University course. We’ve had tens of thousands of enrollments in more than one hundred countries, and more new courses and ways to learn are in the works. For now, we hope that our new self-paced approach makes it even easier and more convenient to level up your Redis skills!

[***Sign up and start learning more about Redis now!***](https://university.redis.com/)

*By Leena Joshi, VP Product Marketing · Published 6 August 2014 · updated 4 March 2025*

![Blog tile image](/images/blog/0073e867b4e64f59de9047fdcde04295ba647e5c-772x550.webp)

Don’t miss [Tung Nguyen’s appearance on stage at NoSQL Now! 2014](https://nosql2014.dataversity.net/sessionPop.cfm?confid=81&proposalid=6837) event, on Tuesday, August 19th, 2014 between 12pm and 12:30pm.

In this 30 min session you will learn how [Bleacher Report used Redis](/blog/redis-labs-performance-testing-with-live-traffic) to build a highly scalable, highly available, and top performing application with sub 60ms response times. Redis is an open source in memory NoSQL database best known for its sub-millisecond latency.

In this session you will learn:

- Why we needed to build the API app.
- Why Bleacher report relies on Redis as a critical infrastructure component.
- How to leverage Redis operations and methods.
- Issues, and lessons learned in building the B/R API service with Redis.
- What we found out about Redis Cloud by Redis vs open-source Redis performance.

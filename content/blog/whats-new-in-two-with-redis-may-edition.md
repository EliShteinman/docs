Welcome to “What’s New in Two,” the place to catch up on the Redis releases you might have missed from last month. In this article, we’ll delve deeper into developments from May, expanding on what I covered in our latest video. I’ve included a video thumbnail above for those who prefer watching a quick recap of this month’s updates. Let’s dive in.

First, some huge news. AWS Marketplace customers can now create Essentials (formerly known as Fixed) subscriptions on their Redis Cloud account and pay for them via AWS Marketplace. What we love about this update is that AWS marketplace customers can get started with as little as $5 a month on Redis Cloud. Try it out now using the 14-day $500 free trial available on the AWS marketplace [pay-as-you-go](https://aws.amazon.com/marketplace/pp/prodview-mwscixe4ujhkq?sr=0-2&ref_=beagle&applicationId=AWSMPContessa) listing. 

Next, we’re thrilled to announce that Redis Cloud now offers support for active-active deployments with search and query functionalities and a robust document store with JSON. This integration is designed to be user-friendly, simplifying the Redis user’s setup to build highly resilient, globally distributed architectures with the flexibility and efficiency of storing and retrieving data meaningful for your business needs with JSON. See [Search and Query Active-Active databases](https://redis.io/docs/latest/operate/oss_and_stack/stack-with-enterprise/search/search-active-active/) to learn how to use Search and Query on Active-Active databases.

Also in Redis Cloud, you can now set the dataset size on a new database. This makes it much easier for our customers to allocate the right amount of memory needed for their use case. For example, if a customer needed to set up high availability, it would allocate the extra memory needed for that setup knowing the dataset size requirements beforehand.

Next, we’re excited to cover that [SAML single sign-on](https://redis.io/docs/latest/operate/rc/security/access-control/saml-sso/) now supports multiple username domains. This helps those organizations who need to use Redis Cloud with multiple domains. Select **Manage domains** on the **Single sign-on** screen to associate additional domains in your SAML setup.

That’s a wrap for this month’s “What’s New in Two,” where we’ve taken a closer look at Redis’ latest features and enhancements in May.

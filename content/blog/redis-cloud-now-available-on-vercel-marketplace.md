*By Sowmya Narayanan, Senior Group Product Manager, Redis · Published 28 August 2024 · updated 11 June 2025*

![Blog tile image](/images/site-mirror/99bdc2facb9b1e27fc2a0e0304366c4c82c0344e-772x552.webp)

Starting today, **Redis Cloud** is available on the **Vercel Marketplace**, unlocking fast data and GenAI use cases for next gen apps for devs building on Next.js. With Redis Cloud, you can build GenAI apps and bring them to production faster, with the speed and efficiency that Redis is known for, right within your Vercel environment.

### Redis Cloud: powering the future of GenAI and Next.js apps

Redis is the backbone of fast data for some of the most innovative GenAI apps in the world. OpenAI is scaling ChatGPT to hundreds of millions of users using Redis. By letting you quickly deploy and integrate the fastest vector search, caches, and online feature stores, and other GenAI infrastructure, apps built on Redis Cloud are delivering better real-time app experiences all at sub-millisecond speeds.

When paired with Next.js, one of the most popular React frameworks, Redis Cloud lets devs create fast, dynamic apps that can scale effortlessly. Whether you’re building AI agents, chatbots, personalization engines, or predictive analytics, Redis Cloud ensures your data is always accessible and lightning fast.

### Why Redis Cloud on Vercel?

Vercel is the go-to Platform-as-a-Service for front-end developers who need performance and scalability. By integrating Redis Cloud into Vercel’s ecosystem, devs can harness the official Redis-as-a-Service from the builders of Redis to power your next gen apps without worrying about the complexities of spinning up, configuring, and managing infrastructure.

Here’s why Redis Cloud is a game-changer for Vercel users:

- **Fast data access**: Redis Cloud delivers sub-millisecond local write and read latency, crucial for workloads where every millisecond counts, with multi-site Active-Active.
- **Seamless Next.js integration**: Use Redis Cloud to cache server-side rendered pages, manage user sessions, and handle real-time data streams with ease, making your Next.js applications faster and more responsive.
- **Advanced vector search**: The Redis Query Engine on Redis Cloud allows you to incorporate sophisticated AI features like similarity search and recommendation systems directly within your Next.js applications.

And lets devs deliver on next gen apps including:

- **AI agents**: Build the fastest agentic architecture with Redis Cloud by making agents faster for more complex reasoning.
- **Real-time chatbots**: Develop chatbots that can process natural language inputs in real-time using Redis Cloud’s unparalleled speed.
- **Personalization engines**: Build real-time recommendation engines that use Redis Cloud to analyze user behavior and deliver personalized content in an instant.
- **Predictive analytics**: Anticipate user needs and deliver insights at the speed of thought. Power real-time ML models with live data processing on Redis Cloud.

### Getting Started

It’s never been easier to add Redis Cloud to your Vercel projects to supercharge and scale your GenAI and Next.js apps. Redis Cloud is available now on the Vercel Marketplace. Join the growing community of dev on the Vercel Marketplace with a few clicks: https://vercel.com/marketplace/redis-cloud

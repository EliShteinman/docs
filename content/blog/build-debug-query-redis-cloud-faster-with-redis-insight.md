[Redis Cloud](https://redis.io/cloud/), the most powerful, scalable managed Redis service, just tripled your productivity, writing fast apps faster. As devs, having the right tools at your fingertips while building, debugging or troubleshooting your app in production saves you time—time you can spend on things you actually enjoy, like reading up on the latest LLMs or, more importantly, choosing your outfit for the next Star Wars convention.

Enter [Redis Insight](https://redis.io/insight/)—the most popular Redis developer tool with an intuitive GUI and advanced CLI—now seamlessly embedded in Redis Cloud. Redis Cloud is now your all-in-one hub to manage databases, inspect data, and explore data path capabilities—all without switching contexts. Whether you need caching, a document store, or a vector database, it’s built to handle it all.

## Real-time data browsing & interaction

Redis doesn’t organize data hierarchically by default, but Redis Insight offers an intuitive list or tree view that makes browsing, filtering, and visualizing key-value data structures effortless. Plus, full CRUD support is available for lists, hashes, strings, sets, sorted sets, streams, and JSON data. It also has formatters like Pickle, Protobuf, 32-bit vector and many others to make your data human-readable.

![Redis Insight Database](/images/blog/743790d8fd5d18397693e0556a4db8bab82a51d4-1600x905.webp)

## Write queries faster

The advanced CLI, available in Workbench, makes building Redis queries simple, even for beginners, with features like syntax highlighting, auto-completion, and in-app command browsing. New to Redis Insight on cloud and desktop is our command auto-complete for Redis Query Engine. This makes it easier and faster to build queries with smart suggestions for indexes, schemas, and expressions.

Plus, Workbench supports visualizing command results for Redis Query Engine and time series data, making it easier to analyze and interact with your data.

![Redis Insight Example](/images/blog/88095ffde425d13ef7edc8a4f29e694cb66ba5db-1600x908.webp)

## Learn at your own speed

Discover Redis features through interactive tutorials. These tutorials will show you how to use Redis’ native JSON data structure to create structured queries and full-text searches, including vector similarity search for your AI use cases.

## How do I get started?

You can sign up for Redis Cloud [here](https://redis.io/try-free/), with a free database to get started fast. Redis Insight on cloud is currently being rolled out to the Redis Cloud Essentials plans, with broader deployment across all Redis Cloud subscription levels as soon as possible.

Redis Insight is available as part of Redis Cloud or can be downloaded [here](https://redis.io/insight/?form=open) as a desktop client. The desktop version allows you to connect to any Redis, whether you’re using Redis Community Edition, Redis Cloud, Redis Software, or Azure Managed Redis.

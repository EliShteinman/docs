## Redis Data Integration 1.12

First, a major release for Redis Data Integration (RDI) for Redis Software. RDI 1.12 brings support for MongoDB & Atlas, so if you’ve been looking for an easy way to sync and cache data from MongoDB into Redis, then get this latest update.

Also in this update came an enhancement to RDI’s APIs - you can now discover source database metadata for specific tables, validate transformation jobs before deploying the pipeline, and modify the existing pipeline by adding/removing tables and transformation jobs. Check out the latest [docs here](https://redis.io/docs/latest/integrate/redis-data-integration/).

## Redis Insight 2.70

Next, Redis Insight, our dev tool, received an update. Redis Insight 2.70 adds support for tagging database connections, making it easier to organize and quickly find what you need. Tags can be created locally or imported from Redis Cloud or Redis Software. Also, in this update, full-value editing and the ability to search within a JSON key have been highly requested. Get the [latest release here](https://redis.io/insight/).

Finally, we have announced the dates and locations of 2025 Redis Released, our worldwide in-person event series. Our attendees will get an exclusive look at our product roadmap and latest releases, grow their network, and learn how businesses across industries are using Redis as the backbone of their real-time experiences and AI initiatives. [Learn more](https://redis.io/released/) about where and when we’ll be hosting these events, and we hope to see you there.

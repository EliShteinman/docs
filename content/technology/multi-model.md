*updated 20 February 2026*

Multiple models in one interface with sub-millisecond latency.

## Benefits

### Simplify multi-model operations

Enable inter-module and module-core data structure operations in efficiently—all at sub-millisecond latency.

### Endless programmability

Program any database logic that combines Redis modules and core operations in Redis.

### Convert to a multi-model database

Easily migrate an existing dataset to a pure multi-model database in Redis by implementing a few simple principles—without changing your database architecture.

## Use cases

### Data ingest

Ingest and process millions of time-stamped data points per second with minimal latency using minimal resources.

### Telemetry

Collect telemetry data from multiple remote IoT devices, on-premises, in any cloud, or on the edge for data-driven insights.

### Monitoring

Gain deep insights into infrastructure and app health with integrations into Prometheus, Grafana, and Telegraf.

### Transaction scoring

Apply machine learning models in real time to any data to score transactions, classify data, and detect any anomalous activity.

### Fraud mitigation

Enable automated pattern discovery across large volumes of streaming transactions to weed out false positives and identify real fraudulent activity.

### Personalization

Customize experiences by providing relevant content instantly based on user preferences, trends, and interactions.

## The key features

### Persistence

We offer persistence options to ensure messages aren’t lost and can be recovered in event of failure. We also provide point-in-time Redis snapshots (RDB) as well as more advanced persistence options, like append-only-file (AOF) persistence that logs every write and persists it to disk.

### Pub/Sub

Broadcast live notifications with pub/sub for instant, efficient and lightweight messaging, perfect for low-latency, high-throughput service interactions.

### Redis streams

Build streaming architectures and persist data effectively with Redis streams, the ideal structure for real-time communication and event sourcing.

### Redis lists and sorted sets

Create simple and efficient message queues using lists for straightforward messaging, and sorted sets for priority queues based on timestamps or scores.

## How it works

## Use less RAM, save more money

Intelligently tier data between RAM and NVMe SSD to access your most essential data with real-time latency, while keeping other data accessible within milliseconds.

## Unlock terabyte scale

Power your feature store, context retrieval, personalization engine, or vector database with the cost-to-performance efficiency needed to power real-time AI/ML at scale.

## Fine-tune cost and performance

Scale smarter with flexible SSD configurations. Configure your RAM ratio from 10-50% to find the ideal balance of performance and cost for your workload.

## Key features

### 250GB-50TB scalability

Break through traditional memory ceilings while maintaining predictable, real-time performance.

### Get more for your money

Use all the infrastructure you pay for with maximum RAM and Flash space utilization.

### Tier the smart way

Automatic hot/warm key management keeps hot data in RAM for sub-millisecond access, while less frequently used keys are tiered to Flash.

### No changes, just savings

Continue using everything you love about Redis (APIs, data types, and speed). No code changes or rework.

### Flexible for any workload

Get consistent speed and efficiency across any workload, regardless of hot data percentage or key value size.

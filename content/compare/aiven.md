## Frequently asked questions

### What is Redis Cloud?

Redis Cloud is designed to deliver the fastest, most reliable, and feature-rich Redis experience available. As the only fully-managed service from the creators of Redis, it offers unparalleled performance, scalability, and reliability for real-time applications. Redis Cloud also provides a comprehensive suite of advanced features and data structures, including auto tiering, query and search, vector search, Redis Data Integration (RDI), and more. Redis Cloud is optimized for the cloud, and backed by a dedicated team of experts.

### What is Aiven?

Aiven is a cloud-based service provider that offers managed open-source data infrastructure. They provide a variety of services, including databases, analytics, and messaging tools. Aiven’s offerings include Aiven for Dragonfly, a Redis fork focused on scalable, basic caching, and Aiven for Valkey, another Redis fork aimed at providing basic, open source caching.

### How do I migrate from Aiven to Redis?

Migrating from Aiven to Redis is easy. Both Dragonfly and Valkey are compatible with a subset of Redis data structures, making their migration to Redis easy. We also offer support for live migrations with [RIOT](https://redis.github.io/riot/).
